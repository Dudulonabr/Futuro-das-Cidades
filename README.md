# Futuro das Cidades

Site sobre **cidades inteligentes, tecnologia urbana, sustentabilidade, sensores, mobilidade elétrica e inovação**.

## Sobre o projeto

A aplicação apresenta conteúdos sobre o futuro dos ambientes urbanos em uma experiência web responsiva, com atenção a semântica, acessibilidade, SEO e organização de conteúdo.

## Destaques

- Layout responsivo
- HTML semântico
- Navegação entre múltiplas páginas
- Blog e página de contato
- Recursos de acessibilidade
- Metadados para SEO
- Open Graph e Twitter Cards
- Dados estruturados com Schema.org
- Scripts de validação, minificação e auditoria

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Chart.js
- Font Awesome
- Node.js / npm para ferramentas de desenvolvimento
